# LoL 敵スキルCD一覧ツール

敵5人の Q/W/E/R の基本クールダウン（ランク別）をウィンドウに一覧表示します。
自分と同じロールの敵（対面）は先頭に ★ 付きで強調されます。
ピック画面では公開された（ロックされた）敵から順に、試合中は5人全員を表示します。

### 表示の折りたたみ
- 対面が分かっているときは対面だけ開き、他の4人は折りたたんだ状態で表示（ロール不明時は全員を開く）。
- チャンピオン名（▼/▶）をクリックでそのチャンピオンを折りたたみ。折りたたみ中は全スキルのCDを1行（ランク1→最大）で表示。
- パッシブ名の「▶ 説明を表示」をクリックで Wiki の説明文を開閉（既定は閉じた状態。CDが書かれていれば右端に表示）。
- 上部のボタンで「全員ひらく / 全員たたむ / P説明を開く / P説明を閉じる」をまとめて切り替え。
- 上部「並び:」のアイコンでスキルの並びを切り替え（選択中は金枠。設定は保存）。
  - 田の字: Q W / E R の2×2（既定）
  - 縦棒4本: Q W E R の横4列（CDは名前の下）
  - 横線4本: Q / W / E / R の縦4行（CDは各行の右端）
- 上部の **「スペルCDを分:秒で」** にチェックすると、サモナースペルのCDを秒（例: 300）から分:秒（例: 5:00）の表示に切り替え（設定は保存）。
- 上部の **「バフ・アイテムを分:秒で」** にチェックすると、タイマー欄のバロンバフ・エルダーバフ・ゾーニャ・GA の時間を秒（例: 180）から分:秒（例: 3:00）の表示に切り替え（設定は保存）。
- チャンピオン名の右端に通常攻撃の射程（Lv1）を表示。トリスターナ・ケイル・ナー（ミニ）などレベルで伸びるチャンピオンは「Lv1→最大 (到達Lv)」。

### タイマー音声
- 上部の **「タイマー音声」** にチェックすると、試合時間が 2分55秒・5分・8分・15分・20分・25分・30分 になったときに「○分経過」と読み上げます（設定は保存）。
- 各時間の1分半前（1分25秒・3分30秒・6分30秒・13分30秒・18分30秒・23分30秒・28分30秒）にも、その時点の経過時間（例:「3分30秒経過」）を読み上げます。
- 読み上げは Windows 標準の音声合成（日本語音声 Haruka）。試合時間は Live Client Data API の `gameTime` から読み、次の確認（2秒ごと）までに来る節目はその時刻に合わせて読み上げます。
- **「○.○ 秒早く」** で読み上げを節目より早められます（0.0〜60.0秒、0.1秒単位。矢印か直接入力して Enter）。音声合成の起動に少しかかるので、遅く感じるときは 0.5〜1.0 秒ほどにすると合いやすいです。
- 途中から接続した場合、過ぎた節目はまとめて読みません。常駐と手動起動のウィンドウが両方動いているときは常駐側だけが読みます。

## 使い方（exe）

`dist\LoL_CT_Tool.exe` を使います（Python 不要。単体でコピーして持ち運び可）。

### 自分で起動する
`LoL_CT_Tool.exe` をダブルクリック → ウィンドウが開き、試合/ピック画面を待って自動で表示。×で終了。

### 自動起動（スタートアップ常駐）
ウィンドウ上部の **「Windows起動時に自動で常駐」** にチェック。

- スタートアップに登録され、その場で常駐も開始します（画面には何も出ません）。
- ピック画面が始まると自動でウィンドウが出て、試合が終わると自動で隠れます。
- ×で閉じるとその試合中は隠れたまま（次の試合でまた出ます）。常駐を完全に止めるにはウィンドウの「終了」ボタン。
- **「クライアント起動時から表示」** にチェックすると、ピック画面を待たずクライアント起動中はずっと表示。
- チェックを外すとスタートアップ登録を解除（今動いている常駐は次の「終了」かPC再起動まで残ります）。

exe を別の場所へ移動した場合は、移動後の exe でチェックを付け直してください（登録先は exe の場所）。

### コマンドライン（任意）
```
LoL_CT_Tool.exe --install-startup     # スタートアップ登録
LoL_CT_Tool.exe --uninstall-startup   # 登録解除
LoL_CT_Tool.exe --resident            # 常駐モードで起動
LoL_CT_Tool.exe --show-on client      # 表示タイミングを「クライアント起動時から」に設定
LoL_CT_Tool.exe --update-days 14      # 新バージョンの確認を14日ごとに（0で確認しない）
LoL_CT_Tool.exe --mock sample_allgamedata.json   # 試合外での表示確認
```

## ダウンロードと自動更新

最新の exe は [Releases](https://github.com/katakarapape/LoL_CT_Tool/releases/latest) から `LoL_CT_Tool.exe` を取得します。

Releases 版の exe は前回の確認から一定期間（既定は1週間）経つと新しいリリースを確認し、あれば自動で
ダウンロードして exe を差し替えます。差し替えは次回起動から反映されます（ウィンドウのタイトルに「更新済み」と出ます）。

確認の間隔はウィンドウ右上の **「更新の確認」** で変更できます（毎日 / 3日 / 1週間 / 2週間 / 30日ごと / 確認しない）。
その隣の **「今すぐ確認」** ボタンで、間隔に関係なくその場で確認できます。
コマンドラインの `--update-days N` でも設定できます（N日ごと、0 で確認しない）。
自分でビルドした exe（バージョン `dev`）は自動更新しません。

### リリースのしかた
`v1.2.3` のようなタグを push すると、GitHub Actions が exe をビルドして Releases に公開します。

```
git tag v1.0.1
git push origin v1.0.1
```

## ビルド

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

`.venv` に PyInstaller を入れて `dist\LoL_CT_Tool.exe` を作ります。Python 版は `python lol_cd_tool.py` でそのまま動きます。

## 仕組み

- ピック画面: LoL クライアントの LCU API（`lockfile` の接続情報を使用、読み取りのみ）
- 試合中: Riot 公式の Live Client Data API（`https://127.0.0.1:2999`）
- スキル名・CD: Data Dragon の最新パッチ `championFull.json`
- サモナースペル（最上段・アイコン付き）: Data Dragon の `summoner.json` とアイコン。
  真TP（10分以降 / 330→240秒）とクエストTP（390秒、TP持ちは真TPが300→210秒）は Data Dragon に無いため、
  LoL Wiki の Teleport 記事を元に `EXTRA_SUMMONERS` に記載（パッチ 16.20 時点）。真TPのアイコンは CommunityDragon から取得。
- オブジェクト・アイテムのタイマー（2段目）: カニ（スカトル）・ドラゴン・エルダー・ヴォイドクラブ・ヘラルド・バロンの出現時間、
  バロンバフ・エルダーバフの効果時間、ゾーニャ・GA のCD。Data Dragon に無いため LoL Wiki を元に
  `TIMERS` に記載（パッチ 16.20 時点）。
- パッシブ: [LoL 日本語 Wiki](https://www.loljp-wiki.jp/wiki/?Champion) の各チャンピオンページから説明文をそのまま表示。
  敵として出てきたチャンピオンのページだけを1件ずつ取得し、パッチごとにキャッシュします。
  Wiki に繋がらない・見つからない場合は Data Dragon の公式説明文を「（公式の説明文）」付きで表示。
- キャッシュ・設定: `%LOCALAPPDATA%\LoL_CT_Tool\`

LoL のインストール先が `C:\Riot Games\League of Legends` 以外でも、起動中のクライアントから自動で探します。

## 注意

- 表示はスキルの基本CDです。スキルヘイスト・アイテム・パッシブによる短縮は反映されません。
- ロール情報が無いモード（練習ツール・一部カスタム等）では対面判定はされません。
- ゲームをフルスクリーンにするとウィンドウが隠れるので、ボーダーレスかセカンドモニター推奨。
- PyInstaller 製の exe はウイルス対策ソフトに誤検知されることがあります。
